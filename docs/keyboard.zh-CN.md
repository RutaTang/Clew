# 键盘操作

[English](keyboard.md) · **简体中文**

Clew 做的每件事都可以只用键盘完成（Linux 和 Windows 上 **⌘** 即 **Ctrl**）：**⌘⇧P** 打开命令面板，可以搜索任意命令——各种图、侧边栏的视图和面板、右键菜单在光标处能做的事、调试器的控制、主题——按回车执行。在文件查找框（⌘P）里输入 `>` 也是一样，**⌘/** 列出所有快捷键。**⌘J** 在屏幕上的每个按钮和每一行旁标出一个由字母组成的短代码——侧边栏里的文件、工具条上的工具、对话框的按钮——输入代码就等于点击它；命令面板也会按名称列出屏幕上能按的东西。**F6** 让键盘在代码、侧边栏的输入框、文件树和 Ask 之间切换；在文件树里，方向键可以逐行走（→ 展开文件夹，← 收起，回车打开文件）。没有输入框占着键盘时，**Tab** 依次圈出屏幕上的每个控件，按回车或空格就会按下它。也可以直接说：**⌘⇧S** 听你说一个命令或一个问题（见[语音](voice.zh-CN.md)）。
