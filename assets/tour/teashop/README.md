# Tea Shop

A small online tea shop: a catalog of teas, orders with discounts, stock
that is set aside at checkout, and a card payment.

- `teashop/models.py` — teas, customers, orders
- `teashop/pricing.py` — what an order costs
- `teashop/checkout.py` — stock, payment, receipt
- `teashop/api.py` — the web API
- `schema.sql` — the database

Run `python main.py` to place two orders.
