# Symbols Nerd Font Mono

`SymbolsNerdFontMono-Regular.ttf` is the symbols-only Nerd Font, bundled to
render file-type icons in the tree. It is part of the Nerd Fonts project
(https://github.com/ryanoasis/nerd-fonts), distributed under the MIT License;
the individual glyph sets it aggregates (Devicons, Seti-UI, Font Awesome, …)
carry their own permissive licenses (MIT / OFL).
